# Python Units 7 & 8 Lab Practical – Set C

## 📌 About the Project
This repository contains solutions for the Python Units 7 & 8 Lab Practical Test (Set C).

The practical covers Python standard modules, custom modules, packages, file handling, and NumPy operations.

## 📚 Topics Covered

### Section A – Python Standard Modules
- datetime and timedelta
- Math and Random modules
- UUID module
- Time module

### Section B – OS, Custom Modules and Packages
- os and shutil modules
- Custom module creation
- Different import methods
- `__name__` and `__main__`
- Packages and sub-packages

### Section C – NumPy
- Creating NumPy arrays
- Array slicing
- Boolean masks
- np.where()
- Views and copies

## 🛠️ Technologies Used
- Python 3
- NumPy
- VS Code

## ▶️ How to Run

1. Clone the repository:

```bash
git clone YOUR_REPOSITORY_URL
```

2. Open the project folder in VS Code.

3. Install NumPy:

```bash
pip install numpy
```

4. Run any Python file:

```bash
python A_standard_modules.py
```
